Motion Studio

Open Motion Studio from the link in your terminal

This tab doesn't have the private key that Motion Studio printed when it started. It keeps other apps and websites on this Mac from controlling your projects.

Terminal
$ npx @motion-studio/cli
Motion Studio is running.
Open: http://127.0.0.1:4318/#t=•••••••••••
Closed the terminal or lost the link? Run this in a new terminal window. It prints the link again without restarting anything.
npx @motion-studio/cli --print-url
Using the desktop app? Open Motion Studio from Applications; it never needs this step.
