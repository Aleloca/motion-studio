Get started.

Motion Studio runs on your computer, in its own desktop window or in your browser.

Read the user guide → Every feature, step by step.

Desktop app

Download for macOS

Every build is in the latest release:

  • macOS: the .dmg for Apple Silicon or Intel, signed and notarized.
  • Windows: the .exe installer, not signed yet (SmartScreen: More info, then Run anyway).
  • Linux: the .AppImage; make it executable and run it.

From source

git clone https://github.com/Aleloca/motion-studio
cd motion-studio
pnpm install
pnpm motion-studio

From npm

npx @motion-studio/cli

Node 22 or newer and Chrome. Starts Motion Studio and opens it in the browser.
