Motion Studio is a local, open-source app on top of Claude Code. Describe what you want, pick channels and formats, and the agent builds a dedicated composition for each one: a live preview right away, and renders on your own computer.

{ features }

Every animation on this page is a Motion Studio composition, played live by its own runtime.

{ formats }

Every format, every channel.

Pick channels and formats, and the agent writes one composition per format, recomposed for its frame instead of cropped. Motion Studio checks each one before it saves the version.

A format can follow another, like TikTok following the Reel: it shares its composition and its render, with no extra agent run.

How it works →

{ preview & editor }

Live preview. Direct edits.

Every composition plays live in the browser, with no render to wait for. Open the editor to change texts, fonts, colours, position, timing and animation presets.

Saving makes a new version with no agent and no tokens. New clips and effects stay with the agent: ask for them in the chat.

The editor →

{ brand }

Your brand, from a site or a codebase.

Point the brand analysis at your website, or at your app's code, which it only reads. It brings back palette, fonts, logos and tone, and every entry says where it came from.

Secret files are never opened, and the agent follows the brand in every creative.

Brand and assets →

{ identity & store }

Logos, icons and store packs.

Identity formats render real file sets: a logo in SVG and PNG, a complete favicon set with its head snippet, iOS and Android app icons, and a social preview.

The store pack plans the screenshots for the App Store, Google Play or both. This site's own logo and favicon came out of Motion Studio.

Identity formats →

{ languages }

Ten languages, one layout.

Translate a version into up to 10 languages. The agent only writes the texts: positions, timings, colours and images stay the original's, and a text that overflows its box is shortened.

Voice-overs can be translated too. Render and export each language with its own file name.

Languages →

{ agent }

Talk to it while it works.

Queue requests for after the current turn, stop at once, or stop and redirect the same job with new instructions.

With Claude Code 2.1.301 or newer, your messages reach the running agent live, and you see when it took them.

The agent →

{ local }

Local, and versioned with git.

Projects are folders of JSON and Markdown on your computer. Every version is a git commit: compare versions, comment on a moment, restart from an earlier one.

Export copies the starred version of each format, named from your own pattern.

Export →

{ paid services }

Paid services, only when you say so.

Images with OpenAI, voice-overs with OpenAI or ElevenLabs, music and sound effects with ElevenLabs, stock photos and videos from Pexels and Unsplash.

Every paid generation asks for confirmation first, unless you turn it off in Settings. API keys stay in the system keychain, and the agent never sees them.

Providers →

{ variants }

Five directions at once.

Ask for up to five variants of a creative, each a different direction for the same brief, across every format. Talk to one variant in the chat, or to all of them at once.

Star the best version of each format, even from different variants, and export the group. Discard the rest; Restore brings one back.

{ get started }

Get started.

Motion Studio runs on your computer and opens in your browser, or in its own desktop window.

From source

Available today.

git clone https://github.com/Aleloca/motion-studio
cd motion-studio
pnpm install
pnpm motion-studio

Builds and starts on 127.0.0.1:4317, then opens the browser.

Read the user guide →: every feature, step by step.

Desktop app

Download the installer from the project's GitHub Releases, once published.

From npm

npx @motion-studio/cli, once published.
